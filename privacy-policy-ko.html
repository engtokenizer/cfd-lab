이 앱은 유동·열전달 계산을 학습하고 실험하는 도구입니다. 계정 가입이나 이름·주소 입력을 요구하지 않습니다. 사용자가 입력한 계산값과 결과, 설정, 보고서 이력은 실행 환경에 따라 아래와 같이 처리됩니다.

Android 앱

계산 입력·결과·이력은 기기의 앱 저장소에 보관됩니다. 앱은 인터넷 권한을 요청하지 않으며 계산 데이터를 자체 서버로 자동 전송하지 않습니다. 사용자가 파일을 내보내거나 PDF를 인쇄하면 Android의 파일 선택기 또는 인쇄 서비스가 선택한 저장 위치에 접근합니다. 외부 저장 제공자나 인쇄 서비스의 처리는 해당 서비스의 정책이 적용됩니다.

웹판

계산·보고서 이력은 접속한 브라우저의 저장소에 보관됩니다. “프로젝트에 저장”을 선택하면 파일을 웹 서버가 실행되는 Yoga 기기의 프로젝트 downloads 폴더에 저장합니다. “외부 브라우저용 다운로드 주소”를 만들면 파일 내용은 서버 메모리에 최대 10분 동안 보관되며, 그 주소를 가진 사람은 유효 기간 중 파일을 받을 수 있습니다. 접속 시 서버는 접속 IP 주소, 요청 경로·시각, 브라우저 정보 등을 운영 기록으로 남깁니다. 이 웹판은 사용자가 해당 서버에 접속할 수 있는 환경에서만 동작합니다.

보관·삭제와 공유

브라우저 이력은 해당 브라우저의 데이터 삭제 또는 앱의 이력 삭제 기능으로, Android 앱 데이터는 기기 설정의 앱 데이터 삭제·앱 제거로 지울 수 있습니다. 프로젝트에 저장한 파일과 서버 운영 기록은 자동 삭제하지 않으며 Yoga 기기의 운영자가 별도로 삭제할 때까지 보관합니다. 원격 이용자는 문의 이메일로 삭제를 요청할 수 있습니다. 내보낸 파일은 사용자가 저장한 위치에서 직접 삭제해야 합니다. 앱이 계산 데이터를 광고 목적으로 제3자에게 자동 전송하는 기능은 없습니다. 사용자가 선택한 외부 저장·공유 서비스로 전송한 파일은 그 서비스의 정책이 적용됩니다.
